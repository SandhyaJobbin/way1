# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Foundation — Design System, Shell & Content Pipeline.
> Serves requirements: SHELL-01, SHELL-02, SHELL-03, SHELL-04, SHELL-06, CONT-01, CONT-02, CONT-03, CONT-04, ASST-01.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Provenance:** Design language LOCKED by PROJECT.md/REQUIREMENTS.md (SHELL-01 tokens) and orchestrator objective — no re-ask. Fonts from ASSETS.md §7 recommendation. Existing codebase scouted: v0 `src/index.css` carries the retired "Warm Night" dark palette + Google-Fonts-CDN imports (Baloo 2 / Nunito Sans) — both are replaced by this contract (CONT-03/CONT-04 scrub + offline-safe self-hosting).

**RFP NEUTRALITY (hard constraint, SHELL-06 / CONT-04):** No target-client name, trademark, logo, or footage anywhere in UI, copy, content JSON, or code identifiers. Token/variable names must be generic (`accentPrimary`, never `<vendor>Blue`). Working brand: **"AV Context Trainer"** (text wordmark, swap-ready via branding config §Branding Config Layer).

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, dot-label micro gaps |
| md | 16px | Default element spacing, card inner padding baseline |
| lg | 24px | Section padding, scrubber dot gap, card padding |
| xl | 32px | Layout gaps, checkpoint label offset |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |
| 4xl | 96px | Cinematic section breathing (design language = huge whitespace) |
| 5xl | 128px | Landing/start-gate vertical rhythm only |

Exceptions: none. Stroke widths (1.5px button border, 2px connectors, 8px route path) are geometry, not spacing. Touch/pointer hit targets minimum 44×44px (invisible hit area around 12px scrubber dots).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 600 | 1.4 |
| Body | 16px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 64px | 600 | 1.05 |

Rules:
- Exactly 2 weights across the app: **400 (regular)** and **600 (semibold)**. No 300/500/700/800.
- Display face = Outfit for Display + Heading roles (rounded geometric sans, SHELL-01). Body face = Manrope for Body + Label roles.
- Display 64px is the desktop (≥1280px) value; responsive clamp `clamp(40px, 5vw, 64px)` permitted below 1280px — one declared size, no additional stops.
- Display/Heading letter-spacing: `-0.01em` (tight, massive rounded type). Label letter-spacing: `0.02em`.
- Long-form body max-width: 65ch (640px). Start-gate industry statement renders at Heading role (24/600) or Display depending on layout — copy is fixed (§Copywriting).

### Radius system (circular motif — SHELL-01)

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | 8px | Small chips |
| `--radius-md` | 16px | Inputs, small cards |
| `--radius-lg` | 24px | Cards, video poster frames |

| `--radius-pill` | 9999px | Buttons (thin circular outline buttons), nav pills, badges |
| circle | 50% | Dots, checkpoint nodes, play buttons, badges |

### Border & shadow policy

- Prefer 1px hairline borders (`rgba(30,35,64,0.08)`) over shadows on the light shell.
- Shadow tokens (only two, used sparingly):
  - `--shadow-lift`: `0 1px 2px rgba(30,35,64,0.06)` — resting cards.
  - `--shadow-float`: `0 12px 32px rgba(30,35,64,0.10)` — hover-elevated cards, start-gate elements, floating nav.
- No glassmorphism, no blur panels (v0 `.glass-panel` retired).

## Phase 1 Screen & Component Contracts

### 1. Start gate / landing screen (SHELL-02)
- Full-viewport `#F5F7FA` canvas. Center column: wordmark (Label-role caps lockup) → Display heading → industry statement (fixed copy above) → primary CTA.
- CTA = thin circular outline pill button: 1.5px border `#1E2340`, transparent fill, pill radius, height 56px, horizontal padding 32px, label "Begin Training" 16/600. Hover: border → `#0080FF`, text → `#0080FF`, bg `rgba(0,128,255,0.04)`.
- Background motif: faint dotted radial pattern (ink at 6% alpha, 2px dots on 24px radial grid rings) behind/beside hero — circular motif per SHELL-01. Optional baked isometric city still (ASSETS.md §9.6 placeholder) right of copy on ≥1280px.
- Click on CTA = the autoplay gesture capture (SHELL-02): single user gesture unlocks audio/media context for the session, then cinematic entry transition (§Motion Contract) routes to shell `/lesson`.
- No video/audio autoplay before the gesture.

### 2. Shell + top nav (SHELL-03)
- Floating top nav: white pill surface (`--radius-pill`, `--shadow-lift`), height 64px, centered horizontally, 24px from top. Contains: wordmark lockup (left, text-only from branding config) · nav links Lesson / Zone (right group).
- Nav link states: idle = ink 60% alpha 16/600; hover = ink 100%; active route = white text on `#1E2340` pill segment (navy segment inside white bar); focus-visible = 2px `#0080FF` ring offset 2px.
- HashRouter routes: `#/lesson`, `#/zone`; unknown hash → redirect `#/lesson`. All navigation via router + AnimatePresence — zero hard page loads (SHELL-03).
- Zone route renders the placeholder empty state (§Copywriting) inside the standard section layout.

### 3. Dot-timeline scrubber (SHELL-03 section navigation)
- Geometry: dots on a horizontal 2px connector line. Idle dot 12px, current dot 16px, gap 24px (center-to-center 36px... use 24px clear gap).
- Dot states: **locked** = `rgba(30,35,64,0.12)` fill · **visited/complete** = `#00E59B` fill · **current** = `#FFFFFF` fill + 2px `#0080FF` ring + soft outer halo (`rgba(0,128,255,0.15)`, 24px) · connector segment behind completed dots fills with blue→teal gradient (progress fill), ahead segments stay `rgba(30,35,64,0.12)`.
- Labels: 14/600 ink, rotated **-45°** (transform-origin: top left), anchored 16px below each dot; at <1024px labels un-rotate to horizontal and truncate with ellipsis at 120px.
- Keyboard: `role="tablist"` container, each dot `role="tab"` + `aria-selected`; ←/→ move focus, Enter/Space activate, Home/End jump first/last. 44×44px hit area per dot.
- Same component serves media timelines in Phase 2 (LESN-05) — API takes `items: {id, label, state}[]` + `onSelect`.

### 4. Global route-path progress visualization (SHELL-04)
- SVG path (thick rounded route metaphor): track stroke 8px round caps `rgba(30,35,64,0.08)`; progress stroke 8px round caps, gradient `#0080FF → #00E59B`, `pathLength` animates 0→current on state change (§Motion).
- Checkpoint nodes on path, 32px circles: **locked** = white fill + 1px hairline border, hollow · **active** = white fill + 2px `#0080FF` ring + pulse halo · **complete** = `#00E59B` fill + white Lucide `check` 16px.
- Node labels 14/600 ink, 8px below node. Renders from global progress store (Zustand) — single route across Lesson + Zone checkpoints (SHELL-04, ASSESS-04 ready).
- Placement Phase 1: shell-level (visible on Lesson + Zone routes), desktop: fixed right rail or section footer band — planner picks placement; contract = always rendered from store state, never hardcoded.

### 5. Placeholder states
- **Video slot:** 16:9 poster frame (ASSETS.md §9.8 placeholder still), `--radius-lg`, 1px hairline border. Center play affordance: 64px circle, 1.5px white border, white Lucide `play` 24px, bg `rgba(30,35,64,0.25)`. Hover: scale 1.06 + bg `rgba(30,35,64,0.4)`. Click with no footage → inline card swap: "Video coming soon" copy (§Copywriting). Slot consumes video config entry (CONT-02: footage ships as content-only change).
- **Coming-soon card:** white surface, `--radius-xl`, `--shadow-lift`, padding 32px, teal dot motif (3 dots, 8px, gradient positions), Heading + body + optional pill CTA. Used for Zone placeholder and all future stubs (LESN-04 state stubs Phase 2).
- **Loading:** 3-dot pulse — 8px ink-40% dots, staggered opacity keyframe 150ms apart; skeleton blocks = `rgba(30,35,64,0.06)` with opacity pulse (no shimmer sweep — reduced-motion safe).
- **Empty:** centered layout, dotted radial motif backdrop (ink 6%), Heading 24/600, body 16/400 max-width 480px, pill CTA.
- **Error:** same skeleton as Empty; icon = Lucide `triangle-alert` inside 48px circle, `#D64545` icon + `rgba(213,69,69,0.08)` circle fill; CTA "Reload".

### 6. Design token architecture (SHELL-01)
Three layers, all CSS custom properties, consumed through Tailwind v4 `@theme`:

| Layer | Prefix | Examples | Rule |
|-------|--------|----------|------|
| Primitive | `--primitive-*` | `--primitive-blue-500: #0080FF`, `--primitive-teal-400: #00E59B`, `--primitive-navy-900: #1E2340`, `--primitive-off-white: #F5F7FA` | Raw values only. Never referenced by components. |
| Semantic | `--sem-*` | `--sem-surface: var(--primitive-off-white)`, `--sem-card: #FFFFFF`, `--sem-ink`, `--sem-accent`, `--sem-accent-2`, `--sem-success`, `--sem-error`, `--sem-focus`, `--sem-border` | Theme-switchable. Dark audit theme overrides these under `[data-theme="audit"]` (stubbed values §Color). |
| Component | `--cmp-*` | `--cmp-button-border: 1.5px`, `--cmp-dot-idle: 12px`, `--cmp-dot-current: 16px`, `--cmp-checkpoint: 32px`, `--cmp-route-stroke: 8px`, `--cmp-nav-height: 64px` | Single-consumer constants. |

- Tailwind v4 `@theme` maps semantic vars to utilities (`--color-surface: var(--sem-surface)` etc.) so classes like `bg-surface`, `text-ink`, `border-line` resolve through the layers.
- Spacing/type/radius scales from this spec registered in `@theme` (`--spacing-*` untouched Tailwind defaults remain valid; custom `--radius-*` per table above).
- v0 tokens (`--c-sky-top`, `--c-wayo-*`, all Warm Night / lesson-zone palettes, `.glass-panel`, `.warm-glow`) deleted (CONT-03).

### 7. Branding config layer (SHELL-06 / CONT-04)
- `src/config/branding.json`, Zod-validated at import boundary:
  ```jsonc
  {
    "name": "AV Context Trainer",          // wordmark text
    "tagline": "Training for the Autonomous Vehicle industry",
    "wordmark": { "mode": "text" },        // or { "mode": "image", "src": "..." } post-award
    "logoSlot": null,                      // post-award logo asset path or null
    "colorOverrides": {                    // all optional; null = token default
      "accentPrimary": null, "accentSecondary": null,
      "surface": null, "ink": null
    }
  }
  ```
- Consumption: `BrandProvider` (React context) parses config once, exposes `brand` object; `colorOverrides` applied as inline `:root` CSS-var overrides (`--sem-accent` etc.) at app mount so every token-driven component restyles with zero code edits.
- Wordmark components read `brand.name` / `brand.wordmark` — never a hardcoded string outside the config default.
- **Identifier hygiene (CONT-04):** no vendor/client substrings in file names, exports, token names, comments, or copy. Repo-wide scrub must return zero hits (Phase 1 success criterion 5).

## Motion Contract (Framer Motion)

| Category | Duration | Easing | Notes |
|----------|----------|--------|-------|
| Micro (hover/press/state tint) | 150ms | `cubic-bezier(0.4, 0, 0.2, 1)` | color/transform only |
| Component enter | 300ms | `cubic-bezier(0.22, 1, 0.36, 1)` | opacity 0→1 + y 16→0 |
| Component exit | 200ms | `cubic-bezier(0.4, 0, 0.2, 1)` | opacity 1→0 + y 0→-16 |
| Route transition (SHELL-03) | 600ms enter / 200ms exit | enter: `cubic-bezier(0.22, 1, 0.36, 1)` | `AnimatePresence mode="wait"`; no hard loads |
| Route-path draw (SHELL-04) | 800ms | `cubic-bezier(0.22, 1, 0.36, 1)` | SVG `pathLength` 0→progress |
| Cinematic start-gate entry | 900ms total | `cubic-bezier(0.22, 1, 0.36, 1)` | gate content: opacity→0 + scale 1→1.02 (500ms) → shell fades/rises in (400ms) |
| Scrubber dot change | spring | stiffness 300, damping 30 | scale/color only |
| Active checkpoint halo pulse | 2000ms loop | ease-in-out | opacity 0.15→0.35, subtle |

Rules:
- Animate `opacity` + `transform` only (GPU-safe); never animate `width/height/top/left`.
- Entry choreography stagger ≤ 80ms between siblings; total landing choreography ≤ 1.6s.
- **Reduced motion (mandatory):** wrap app in `MotionConfig reducedMotion="user"`. Under `prefers-reduced-motion: reduce`: all transitions become opacity-only ≤150ms; route-path draws and dot ripples render final state instantly; scrubber/route changes jump without transform animation; checkpoint pulse disabled.
- Exit-before-enter for route swaps (`mode="wait"`) — no overlapping full-screen canvases.

## Interaction Contract

| State | Contract |
|-------|----------|
| Hover | 150ms. Outline buttons: border+text → accent, bg tint 4%. Cards: `--shadow-lift` → `--shadow-float`, no translate. Dots: scale 1.15. |
| Focus-visible | 2px solid `#0080FF`, 2px offset, on every interactive element, keyboard-only trigger (`:focus-visible`). Never remove outline without replacement. |
| Active/pressed | scale 0.97, 100ms, on buttons/dots/checkpoints. |
| Disabled | opacity 40%, `cursor: not-allowed`, no hover/focus response. Phase 1 usage: none required — reserved contract. |
| Keyboard nav | Scrubber: tablist/tab + arrow/Home/End (§Dot-timeline). Nav links: standard tab order, Enter activates. All interactive elements reachable via Tab in DOM order; no keyboard traps. |
| Pointer targets | ≥44×44px hit area for all interactive elements (12px dots get invisible 44px hit pads). |
| Viewport | Desktop-first audit grade ≥1024px (SHELL-05 lands Phase 4; Phase 1 shell must not break 768–1024px). `overflow` policy: app shell scrolls vertically per route; start gate is fixed viewport. |
