# Plan 02-02: Gesture + Canvas — JogDial and CanvasSequence

## Objective
Build the tactile JogDial drag control (use-gesture + react-spring with inertia detents) and the CanvasSequence frame player that reacts to jogPos from the store.

## Tasks

<task id="T1" name="build-jogdial">
  <read_first>src/store/useStore.ts</read_first>
  <action>
Create `src/components/JogDial.tsx`. The component must:

1. Accept props: `{ size?: number; detents?: number; className?: string }` — all optional with defaults `size=160`, `detents=10`.
2. Import `useDrag` from `@use-gesture/react`, `useSpring` and `animated` from `@react-spring/web`, `useRef` from `react`, and `useStore` from `../store/useStore`.
3. Constants at module scope:
   - `MAX_DRAG_PX = 320` — full-range drag in pixels
   - `MAX_DEGREES = 270` — visual rotation range
4. Zustand: call `const setJogPos = useStore(s => s.setJogPos)` — read only the setter, no re-render subscription to `jogPos`.
5. `posRef = useRef(0)` — tracks current 0–1 position without causing re-renders.
6. `const [{ rotate }, api] = useSpring(() => ({ rotate: 0 }))`.
7. `useDrag` binding:
   ```ts
   const bind = useDrag(({ offset: [ox], velocity: [vx], last }) => {
     const clamped = Math.max(0, Math.min(MAX_DRAG_PX, ox));
     const pos = clamped / MAX_DRAG_PX;
     const deg = pos * MAX_DEGREES;
     posRef.current = pos;
     setJogPos(pos);
     if (last) {
       // snap to nearest detent
       const snapped = Math.round(pos * detents) / detents;
       posRef.current = snapped;
       setJogPos(snapped);
       // inertia flywheel: spring with decay from release velocity
       const target = snapped * MAX_DEGREES + vx * 40;
       api.start({ rotate: target, config: { decay: true } });
       api.start({ rotate: snapped * MAX_DEGREES, config: { tension: 200, friction: 26 } });
     } else {
       api.start({ rotate: deg, config: { tension: 120, friction: 18 } });
     }
   }, { axis: 'x', bounds: { left: 0, right: MAX_DRAG_PX }, rubberband: true });
   ```
8. JSX: `<div style={{ touchAction: 'none', width: size, height: size, cursor: 'grab' }} {...bind()}>` wrapping `<animated.div style={{ rotate, width: size, height: size, borderRadius: '50%', background: 'radial-gradient(circle at 35% 35%, #3a3a3a, #111)', border: '2px solid #444' }}>` with a tick-mark indicator `<div style={{ position: 'absolute', top: 8, left: '50%', transform: 'translateX(-50%)', width: 3, height: 16, background: '#4db8ff', borderRadius: 2 }} />`.
9. Export as named export: `export function JogDial(...)`.
  </action>

<task id="T2" name="build-canvas-sequence">
  <read_first>src/store/useStore.ts</read_first>
  <action>
Create `src/components/CanvasSequence.tsx`. The component must:

1. Accept props: `{ width?: number; height?: number; frameCount?: number; className?: string }` — all optional with defaults `width=640`, `height=360`, `frameCount=30`.
2. Import `useRef`, `useEffect` from `react` and `useStore` from `../store/useStore`.
3. Subscribe to jogPos: `const jogPos = useStore(s => s.jogPos)`.
4. `canvasRef = useRef<HTMLCanvasElement>(null)`.
5. `framesRef = useRef<HTMLImageElement[]>([])` — preload attempt (no real frames yet).
6. On mount (`useEffect([], [])`): attempt to preload frames from `public/frames/` path pattern `f0000.jpg` through `f{frameCount-1}.jpg` (padded to 4 digits). Store loaded images in `framesRef.current`. This is non-blocking — if images 404, `framesRef.current` stays empty.
7. On `jogPos` change (`useEffect([jogPos])`): wrap paint in `requestAnimationFrame` to avoid synchronous canvas write:
   ```ts
   const raf = requestAnimationFrame(() => {
     if (!canvasRef.current) return;
     const ctx = canvasRef.current.getContext('2d');
     if (!ctx) return;
     const idx = Math.floor(jogPos * (frameCount - 1));
     const img = framesRef.current[idx];
     if (img?.complete && img.naturalWidth > 0) {
       ctx.drawImage(img, 0, 0, width, height);
     } else {
       // procedural placeholder: dark background + frame-number overlay
       ctx.fillStyle = '#0a0e1a';
       ctx.fillRect(0, 0, width, height);
       ctx.strokeStyle = '#1a2a3a';
       ctx.lineWidth = 1;
       // road silhouette lines
       ctx.beginPath(); ctx.moveTo(width * 0.4, height); ctx.lineTo(width * 0.45, height * 0.5); ctx.stroke();
       ctx.beginPath(); ctx.moveTo(width * 0.6, height); ctx.lineTo(width * 0.55, height * 0.5); ctx.stroke();
       ctx.fillStyle = '#4db8ff';
       ctx.font = `bold 14px monospace`;
       ctx.textAlign = 'center';
       ctx.fillText(`FRAME ${idx + 1} / ${frameCount}`, width / 2, height - 16);
       ctx.fillStyle = 'rgba(77,184,255,0.15)';
       ctx.fillRect(0, height - 4, width * jogPos, 4);
     }
   });
   return () => cancelAnimationFrame(raf);
   ```
8. JSX: `<canvas ref={canvasRef} width={width} height={height} className={className} style={{ display: 'block' }} />`.
9. Export as named export: `export function CanvasSequence(...)`.
  </action>

## must_haves
- truths:
  - JogDial writes to store via `setJogPos` — it never reads `jogPos` from store (no subscription → no re-render loop)
  - CanvasSequence subscribes to `jogPos` — this is the only component in this wave that re-renders on dial movement
  - Canvas paint is always wrapped in `requestAnimationFrame` — no synchronous drawImage inside useEffect
  - Both files compile clean with `npx tsc --noEmit`

## Artifacts this phase produces
- `src/components/JogDial.tsx` — drag-to-rotate control, writes jogPos to store, detent snap + inertia on release
- `src/components/CanvasSequence.tsx` — reads jogPos, paints image frames or procedural placeholder
