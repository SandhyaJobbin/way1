**WebGL feature-detect function** (module scope):
```ts
function hasWebGL(): boolean {
  try {
    const canvas = document.createElement('canvas');
    return !!(canvas.getContext('webgl') || canvas.getContext('experimental-webgl'));
  } catch {
    return false;
  }
}
```

**Point-cloud data generator** (module scope, memoizable):
```ts
function generateCloud(count = 3000): Float32Array {
  const pos = new Float32Array(count * 3);
  for (let i = 0; i < count; i++) {
    // road strip: x ∈ [-8,8], z ∈ [-20,20], y near 0
    pos[i * 3]     = (Math.random() - 0.5) * 16;
    pos[i * 3 + 1] = (Math.random() - 0.5) * 0.4;
    pos[i * 3 + 2] = (Math.random() - 0.5) * 40;
    // scatter 20% of points wider (curb/surroundings)
    if (Math.random() < 0.2) pos[i * 3] *= 2.5;
  }
  return pos;
}
```

**Vertex shader string** (module scope):
```glsl
const vertexShader = `
  uniform float uTime;
  uniform float uProgress;
  void main() {
    vec3 pos = position;
    float reveal = step(length(pos.xz) * 0.05, uProgress);
    pos.y += sin(uTime * 1.2 + pos.x * 0.5) * 0.05 * reveal;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    gl_PointSize = max(1.0, 3.0 - length(pos) * 0.04) * reveal;
  }
`;
```

**Fragment shader string** (module scope):
```glsl
const fragmentShader = `
  void main() {
    float d = length(gl_PointCoord - 0.5);
    if (d > 0.5) discard;
    gl_FragColor = vec4(0.31, 0.76, 0.97, (1.0 - d * 2.0) * 0.8);
  }
`;
```

**Inner scene component** `function CloudScene({ jogPos }: { jogPos: number })`:
1. `const positions = useMemo(() => generateCloud(3000), [])` — static geometry, generated once.
2. `const uniforms = useRef({ uTime: { value: 0 }, uProgress: { value: 0 } })`.
3. `useFrame(({ clock }) => { uniforms.current.uTime.value = clock.elapsedTime; uniforms.current.uProgress.value = jogPos; })` — reads `jogPos` from prop via closure, NOT from useStore. No React subscription here.
4. Return:
```tsx
<points>
  <bufferGeometry>
    <bufferAttribute attach="attributes-position" array={positions} itemSize={3} count={positions.length / 3} />
  </bufferGeometry>
  <shaderMaterial
    vertexShader={vertexShader}
    fragmentShader={fragmentShader}
    uniforms={uniforms.current}
    transparent
    depthWrite={false}
  />
</points>
```

**Exported wrapper component** `export function LidarCloud({ className }: { className?: string })`:
1. Read jogPos from store: `const jogPos = useStore(s => s.jogPos)`.
2. If `!hasWebGL()` return `<LidarSVGFallback className={className} />`.
3. Otherwise return:
```tsx
<div className={className} style={{ minHeight: 200 }}>
  <Canvas
    camera={{ position: [0, 14, 0], fov: 55, up: [0, 0, -1] }}
    gl={{ powerPreference: 'default', antialias: false }}
    style={{ width: '100%', height: '100%' }}
  >
    <CloudScene jogPos={jogPos} />
  </Canvas>
</div>
```

## must_haves
- truths:
  - `useFrame` reads `jogPos` via a prop closure — never via `useStore` subscription inside the R3F scene — so R3F's frame loop never triggers React renders
  - `CloudScene` is never exported — it is an internal implementation detail of `LidarCloud.tsx`
  - GLSL shaders are plain template-literal strings — no external `.glsl` files, no webpack loader needed
  - `<Canvas>` receives `gl={{ powerPreference: 'default', antialias: false }}` — SCORM LMS compatibility
  - `<Canvas>` parent div has `style={{ minHeight: 200 }}` to prevent zero-height invisible canvas (R2 risk from RESEARCH.md)
