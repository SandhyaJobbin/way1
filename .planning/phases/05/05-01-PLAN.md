# 05-01 — Scenario Content & Zustand Slice

**Phase:** 5 — Triage Ops Vertical Slice (The Demo)
**Depends on:** 03-06 (Speech system), 03-02 (Global Canvas)
**Effort:** S
**Status:** READY

## Goal

Seed the demo's data layer: incident scenario content, triage routing choices, and a Zustand slice that tracks the operator's decision state across Act 1 → Zone 2 → the seam to Zone 3.

## Tasks

- [ ] **T1 — Scenario content file** `src/content/scenario-data.ts`
  - Define `TRIAGE_INCIDENT` object: id `TRI-2291-RA`, source, timestamp, type, severity, confidence (0.17), sensor fusion tags
  - Define `TRIAGE_ROUTING_OPTIONS` array: 3 options (Forward to Fleet Ops / Send to Annotation Studio / Escalate to Safety Lead) each with label, icon, reason code, recommended flag
  - Define `ACT1_NARRATIVE` array: 5 speech lines covering autonomy loop intro → low-confidence trigger → handoff to triage
  - Define `ZONE2_NARRATIVE` array: 5 speech lines for the triage console walkthrough
  - Export types: `IncidentData`, `RoutingOption`, `NarrativeLine`

- [ ] **T2 — Triage store slice** `src/store/triageSlice.ts`
  - New Zustand slice (merged into existing store via `create` middleware or standalone):
    - `selectedRouting: RoutingOption | null` — current routing choice
    - `triageComplete: boolean` — whether routing was confirmed
    - `seamPayload: { incidentId: string; reasonCode: string } | null` — what Zone 3 receives
    - `selectRouting(option)` — sets selectedRouting
    - `confirmRouting()` — sets triageComplete, generates seamPayload
    - `resetTriage()` — clears for replay
  - Wire into existing `useStore` via `create` merge or re-export

- [ ] **T3 — Update speech-data.ts** `src/content/speech-data.ts`
  - Replace placeholder `act1` lines with `ACT1_NARRATIVE` content
  - Replace placeholder `zone2` lines with `ZONE2_NARRATIVE` content
  - Ensure `SpeechBubble` consumes updated lines

## Verification

1. `npx vitest run src/store/triageSlice.test.ts` — slice actions mutate state correctly
2. Import `TRIAGE_INCIDENT` in a scene file, confirm no TS errors
3. `selectRouting` → `confirmRouting` → `seamPayload` non-null with correct reasonCode
